# facts-module-registry

facts-module-registry holds the module yaml file associated with each module in the FACTS2 ecosystem. The registry acts as the interface between the FACTS2 module ecosystem and [facts-experiment-builder]() (FEB). For a module to be usable by FEB, it must have a yaml submitted to the registry that is up-to-date with the current version of the module's containerized application. For more detail on how to write and maintain a module yaml, see our **module contributor docs**.
